Agent de veille autonome

Confiez une veille à un agent.
Reprenez la main quand vous voulez.

Lockin explore seul les sources que vous autorisez, dans un budget borné, et tient un journal qui permet de retrouver exactement où il en est. À tout moment.

0 / 5

L'agent ne lira que ces domaines. Entrée ou virgule pour ajouter, Retour arrière pour retirer le dernier.

Tentatives d'outils : recherche, lecture, sauvegarde — les échecs comptent aussi.

Échéance indépendante du budget. L'agent s'arrête au premier des deux atteint.

Budget borné

Chaque action consomme une unité. Le modèle ne peut ni en demander plus, ni contourner la limite.

Arrêt immédiat

Dès que le serveur reçoit l'ordre, plus aucune nouvelle action n'est lancée. Les résultats restent.

Journal reconstituable

Chaque événement porte l'heure et le budget restant. On retrouve l'état exact à n'importe quel instant.

Mode démonstration : données simulées dans le navigateur, aucun appel réseau. Retirez ?demo de l'URL pour utiliser le vrai service.
